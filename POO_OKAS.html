Programación Orientada a Objetos

Paradigma que organiza el código en objetos que combinan datos y comportamiento.

La Programación Orientada a Objetos (POO) es un paradigma que organiza el código en torno a objetos: entidades que agrupan datos (atributos) y comportamientos (métodos). Python soporta la POO de forma nativa y elegante, permitiendo modelar el mundo real de manera intuitiva. Dominar este paradigma es esencial para escribir código reutilizable, mantenible y escalable.

📂

Clases y Objetos

la clase Perro es el molde; "Firulais" es un objeto creado a partir de ella.

📂 Clase

Una clase es una plantilla o molde que define las características (atributos) y comportamientos (métodos) que tendrán los objetos creados a partir de ella. La clase no representa un elemento específico, sino una descripción general.
Analogía
Si pensamos en un automóvil:

  • La clase sería el plano de diseño.
  • Los objetos serían los automóviles fabricados usando ese plano.

🔤 Sintaxis:

class NombreClase:
    pass

💻 Ejemplo:

class Motor:
    pass

Aquí se define una clase llamada Motor.

📂 Objeto

Un objeto es una instancia de una clase.
Es decir, es un elemento real creado a partir del molde definido por la clase.

🔤 Sintaxis:

objeto = NombreClase()

💻 Ejemplo:

class Motor:
    pass

motor1 = Motor()
motor2 = Motor()

Se crean dos objetos diferentes:

  • motor1
  • motor2

Ambos pertenecen a la clase Motor.

Atributos

Variables que almacenan el estado o las características de un objeto.

📂 Atributos

Los atributos son variables que almacenan información relacionada con un objeto.
Representan las características o propiedades del objeto.
Ejemplo de características de un motor

  • potencia
  • voltaje
  • velocidad
  • corriente

Estas características pueden almacenarse como atributos.

📂 Tipos de Atributos

Los atributos suelen clasificarse en:

  • Atributos de instancia
  • Atributos de clase

📂 Atributos de instancia

Los atributos de instancia son especificos de un objeto de forma individual (cada objeto posee su propia copia del atributo) y se definen dentro del método __init__.

💻 Ejemplo:

Python ejemplo 
class Motor:

    def __init__(self, potencia):
        self.potencia = potencia	# atributo de instancia

motor1 = Motor(10)
motor2 = Motor(20)

print(f"Motor 1 - Potencia: {motor1.potencia} HP")
print(f"Motor 2 - Potencia: {motor2.potencia} HP")
salida 
Motor 1 - Potencia: 10 HP
Motor 2 - Potencia: 20 HP

Cada motor tiene una potencia diferente.

📂 Atributos de clase

Los atributos de clase pertenecen a la clase completa y son compartidos por todos los objetos.

💻 Ejemplo:

Python ejemplo 
class Motor:

    fabricante = "ABB"	            # atributo de clase

    def __init__(self, potencia):
        self.potencia = potencia	# atributo de instancia

motor1 = Motor(10)
motor2 = Motor(20)

print(f"Motor 1 - Fabricante: {motor1.fabricante}")
print(f"Motor 2 - Fabricante: {motor2.fabricante}")
salida 
Motor 1 - Fabricante: ABB
Motor 2 - Fabricante: ABB

El atributo fabricante es común para todos los objetos.

Métodos

Funciones definidas dentro de una clase que describen el comportamiento o las acciones que un objeto puede realizar.

📂 Métodos

Los métodos son funciones definidas dentro de una clase.
Describen las acciones que puede realizar un objeto.

📂 Tipos de Métodos

Los métodos pueden clasificarse en:

  • Métodos de instancia
  • Métodos de clase
  • Métodos estáticos
  • Métodos especiales o mágicos

📂 Métodos de instancia

Son los más comunes. Trabajan con atributos del objeto mediante el parámetro self.

🔤 Sintaxis:

class NombreClase:

    def método(self):
        instrucciones

💻 Ejemplo:

Python ejemplo 
class Motor:

    def __init__(self, potencia):
        self.potencia = potencia

    def mostrar(self):	# método de instancia
		print(f"Potencia: {self.potencia} HP")

motor = Motor(10)
motor.mostrar()
salida 
Potencia: 10 HP

📂 Métodos de clase

Trabajan con la clase y no con un objeto específico.
Utilizan el parámetro cls.
Los métodos de clase se definen utilizando el decorador @classmethod.

🔤 Sintaxis:

class NombreClase:

	@classmethod
    def método(cls):
        instrucciones

💻 Ejemplo:

Python ejemplo 
class Motor:

    fabricante = "ABB"

    @classmethod
    def mostrar_fabricante(cls):
        print(f"Fabricante: {cls.fabricante}")

motor = Motor()
motor.mostrar_fabricante()
salida 
Fabricante: ABB

📂 Métodos estáticos

No utilizan ni self ni cls.
Son funciones relacionadas con la clase, pero independientes de sus atributos.
Los métodos estáticos se definen utilizando el decorador @staticmethod.

🔤 Sintaxis:

class NombreClase:

	@staticmethod
    def método():
        instrucciones

💻 Ejemplo:

Python ejemplo 
class Motor:

    fabricante = "ABB"

    @staticmethod
    def funcion():
        pass

motor = Motor()
...
salida 
Fabricante: ABB

📂 Métodos especiales

Los métodos especiales (o dunder methods, de double underscore) permiten que tus clases se comporten como tipos nativos de Python: que puedan sumarse, compararse, imprimirse o iterarse. Python los invoca automáticamente en respuesta a operadores y funciones integradas (built-in).
Gracias a ellos, tus propias clases pueden comportarse como los tipos nativos (números, listas, diccionarios, etc.). A esto se le llama a veces el "modelo de datos" de Python.

🔤 Sintaxis:

class NombreClase:

    def __método__():
        instrucciones

💻 Ejemplo:

Python ejemplo 
class Motor:

    def __init__(self, potencia):	# método especial
        self.potencia = potencia

    def mostrar(self):			   # método de instancia
		print(f"Potencia: {self.potencia} HP")

motor = Motor(10)
motor.mostrar()
salida 
Fabricante: ABB

Estos son algunos métodos especiales:

Método especial Descripción
__new__ Crea y devuelve una nueva instancia del objeto (antes de __init__). Recibe la clase (cls) como primer parámetro. Se usa sobre todo con tipos inmutables, singletons o fábricas.
__del__ Se ejecuta cuando el objeto está a punto de ser destruido (finalizador). No garantiza un momento exacto de ejecución; no se recomienda para liberar recursos críticos.
__init__ Inicializa la instancia recién creada: asigna atributos y valores de partida. Se ejecuta justo después de __new__. Debe devolver None.
__str__ Devuelve una representación en cadena legible para el usuario. La usan str() y print(). Debe devolver un str.
__format__ Devuelve una representación en cadena según un especificador de formato. La usan format() y los f-strings con :spec. Debe devolver un str.
__repr__ Devuelve una representación en cadena precisa, orientada a desarrolladores (ideal si es reproducible con eval). La usan repr() y la consola interactiva. Debe devolver un str.

❓ Cuándo usarlos

Método Recomendación
__new__ Sobrescríbelo solo si de verdad necesitas controlar la creación (inmutables, singleton, caché).
__init__ Mantenlo simple: asignar y validar. Evita lógica pesada o efectos secundarios raros.
__del__ Evítalo si puedes; prefiere with / contextlib / weakref.finalize.
__str__ Opcional; solo si quieres una salida distinta (más amigable) que __repr__.
__repr__ Defínelo para depurar.
__format__ Solo si necesitas formatos especiales (ej. distintas unidades, escalas, notaciones).

Encapsulamiento

Principio que oculta el estado interno de un objeto.

📂 Encapsulamiento

La encapsulación es un principio fundamental de la programación orientada a objetos (POO) que consiste en agrupar datos (atributos) y métodos (funciones) que operan sobre esos datos dentro de una única unidad, denominada clase. Los principales objetivos de la encapsulación son:

  1. Ocultación de datos: La encapsulación oculta los detalles de implementación interna de un objeto al exterior, impidiendo el acceso directo a sus datos. Esto protege los datos de modificaciones accidentales y garantiza su integridad.
  2. Control de acceso: La encapsulación permite controlar el acceso a los datos y métodos del objeto mediante la definición de modificadores de acceso (público, protegido y privado) que determinan el nivel de accesibilidad.

Sin embargo, Python no implementa estos modificadores de acceso explícitos. En cambio, el lenguaje se basa en convenciones de nomenclatura para indicar la accesibilidad prevista:


1. Público (sin prefijo): Indica que el atributo/método es accesible desde cualquier lugar, dentro y fuera de la clase.

💻 Ejemplo:

Python ejemplo 
class Persona:
    def __init__(self, nombre):
        self.nombre = nombre  # atributo público

p = Persona("Ana")
print(p.nombre)  # ✅ "Ana"
salida 
Ana

2. Protegido (un guión bajo: _ ): Indica que el atributo/método es de uso interno de la clase y sus subclases. Es solo una convención: técnicamente sigue siendo accesible desde fuera.

💻 Ejemplo:

Python ejemplo 
class Persona:
    def __init__(self, nombre):
        self._nombre = nombre  # "no deberías tocar esto desde fuera"

p = Persona("Ana")
print(p._nombre)  # ⚠️ Funciona, pero va contra la convención
salida 
Ana

Se usa para decirle a otros desarrolladores: "esto es un detalle de implementación, no lo uses directamente."

3. Privado (dos guiones bajos: __ ): Python aplica name mangling: el intérprete renombra el atributo internamente a _NombreClase__atributo, haciendo más difícil (pero no imposible) acceder a él desde fuera.

💻 Ejemplo:

Python ejemplo 
class Persona:
    def __init__(self, nombre):
        self.__nombre = nombre  # privado

p = Persona("Ana")
print(p.__nombre)          # ❌ AttributeError
print(p._Persona__nombre)  # ✅ Accesible con el nombre "mangleado"
salida 
Ana
📝 Nota:

En Python, lo más común es utilizar atributos públicos.
Esto puede sorprender a quienes vienen de lenguajes como C++, Java o C#, donde los atributos suelen declararse privados.

📝 Filosofía de Python:

Python sigue la filosofía:


"We're all consenting adults here."


Es decir, se confía en que el programador usará los objetos correctamente.
Por ello, no existe una verdadera restricción de acceso como private o protected de otros lenguajes.

💡 Punto clave:

Python sigue la filosofía "we're all consenting adults here": confía en que los desarrolladores respetan las convenciones en lugar de imponer restricciones duras. El doble guión bajo no es un candado, es más bien una señal de "en serio, no toques esto".

Properties

Mecanismos que permiten acceder y modificar un atributo privado como si fuera público.

📂 Properties

Una property (propiedad) es un mecanismo que permite controlar el acceso a un atributo como si fuera una variable normal, pero ejecutando métodos internamente.
Esto permite:

  • Validar datos.
  • Restringir accesos.
  • Realizar cálculos automáticos.
  • Mantener el encapsulamiento.

Una property suele definirse mediante tres elementos:

🔤 Sintaxis:

  1. Getter
  2. Setter
  3. Deleter (opcional)

📂 Getter

Permite obtener el valor.

🔤 Sintaxis:

class NombreClase:

    @property
    def atributo(self):
        ...

💻 Ejemplo:

Python ejemplo 
class Persona:

    def __init__(self):
        self._edad = 0

    @property
    def edad(self):
        return self._edad

p = Persona()

print(p.edad)
salida 
...

Observa que:
p.edad
parece un atributo, pero en realidad ejecuta:
edad()

📂 Setter

Permite asignar un valor.

🔤 Sintaxis:

class NombreClase:

    @atributo.setter
    def atributo(self, valor):
        ...

💻 Ejemplo:

Python ejemplo 
class Persona:

    def __init__(self):
        self._edad = 0

    @property
    def edad(self):
        return self._edad

    @edad.setter
    def edad(self, valor):
        self._edad = valor
		
p = Persona()

p.edad = 25
salida 
...

Python ejecuta:
p.edad(25)
internamente (conceptualmente).

📂 Deleter

Permite definir qué ocurre cuando se utiliza del.

🔤 Sintaxis:

class NombreClase:

	@atributo.deleter
    def atributo(self):
        ...

💻 Ejemplo:

Python ejemplo 
class Persona:

    def __init__(self):
        self._edad = 20

    @property
    def edad(self):
        return self._edad

    @edad.deleter
    def edad(self):
        print("Edad eliminada")
        del self._edad

p = Persona()

del p.edad
salida 
Edad eliminada

...

📂 Ventajas de las Properties

  • Encapsulan los datos.
  • Permiten validar información.
  • Mantienen una sintaxis sencilla.
  • Evitan modificaciones incorrectas.
  • Facilitan cambios futuros sin modificar el código cliente.

La principal ventaja de las properties es que permiten que un atributo se utilice como una variable normal (obj.edad), mientras que internamente Python ejecuta métodos que pueden validar, calcular o controlar el acceso a los datos. Esto proporciona encapsulamiento sin complicar la sintaxis para quien utiliza la clase.

📝 Nota:

El deleter es el menos común de los tres. En la práctica casi siempre verás solo el getter, o getter + setter cuando se necesita validación.

Diagramas de Clases

Representación gráfica (UML) de la estructura de un sistema.

📂 Diagramas de clase

Los diagramas de clase son una notación visual del estándar UML (Unified Modeling Language) para representar la estructura de un sistema orientado a objetos. Muestran clases, sus atributos, métodos y las relaciones entre ellas. Son independientes del lenguaje y ampliamente usados en diseño de software.

📂 Estructura básica

Una clase se representa mediante un rectángulo dividido en tres secciones: 


+-------------------+
|      Persona      |
+-------------------+
| + nombre: str     |
| + edad: int       |
+-------------------+
| + saludar(): str  |
| + mostrar(): None |
+-------------------+
Figura 1. Diagrama de clases.

1. Nombre de la clase
Se coloca en la parte superior.
Persona
Generalmente se escribe:

  • En singular
  • Con la primera letra de cada palabra en mayúscula (PascalCase)

Ejemplos:
Persona
CuentaBancaria
Vehiculo
Estudiante


2. Atributos
Se colocan en la sección central.
- nombre : str
- edad : inr


3. Métodos
Se colocan en la sección inferior.
+ saludar(): str
+ cumplirAnios(): void


Visibilidad de atributos/métodos

+ nombre: str

Protegido (#)
# salario: float

Sintaxis UML de un atributo
visibilidad nombre : tipo


Sintaxis UML de un método
visibilidad nombre(parámetros): tipo_retorno



El siguiente código implementa el diagrama de clases UML presentado en la figura 1. 

class Persona:

    def __init__(self, nombre: str, edad: int):
        self.nombre = nombre
        self.edad = edad

    def saludar(self) -> str:
        return f"Hola, me llamo {self.nombre}"

    def mostrar(self) -> None:
        print(f"Nombre: {self.nombre}")
        print(f"Edad: {self.edad} años")

Tipos de relaciones UML

Relación Símbolo Significado
Herencia ──▷ "es un"
Composición ──◆ "está compuesto de"
Agregación ──◇ "tiene un"
Asociación ── "usa un"
Dependencia - -> "depende de"
📝 Nota:

Python no tiene visibilidad real (público/privado/protegido). La convención es: atributo = público, _atributo = protegido (convención), __atributo = privado (name mangling). UML mapea estos prefijos a +, # y - respectivamente.
